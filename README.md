# talon-os-simulation

A minimal, multi-language operating system simulation experiment in Go, C, and C++.

## Structure

```
├── main.go              # Top-level entry point (Go)
├── kernel/
│   └── kernel.c         # Kernel simulation (C)
└── system/
    └── free-h.cpp       # System utility simulation (C++)
```
